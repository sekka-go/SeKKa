# سِكّة | SeKKa

تطبيق رحلات مشتركة يومية وباقات أسبوعية وشهرية. الواجهة عربية RTL ومتجاوبة، وتدعم Faster وSaver، والواجهة الخلفية المستضافة تستخدم Supabase Edge Functions وPostgreSQL.

## التطوير المحلي

يتطلب Node.js 22 أو أحدث. لتشغيل نسخة التطوير المحلية الحالية افتح نافذتين:

```powershell
cd server
npm install
npm run dev
```

```powershell
cd web
npm install
npm run dev
```

افتح `http://127.0.0.1:5173/`. في وضع التطوير يمرر Vite طلبات `/api` إلى Express المحلي على المنفذ 3001، وتُنشأ قاعدة SQLite المحلية في `server/data/sekka.db`.

## النسخة المستضافة

- واجهة الويب تُنشر على Cloudflare Pages وتدعم التثبيت كتطبيق PWA؛ تفاصيل التثبيت والعمل دون اتصال في [دليل PWA](docs/pwa.md).
- الواجهة الخلفية وقاعدة البيانات المستضافتان هما Supabase للمشروع `uorxfakceqnhxqnaawdy`.
- الواجهة تستخدم رابط Edge Function المعتمد تلقائيًا في بناء الإنتاج. لا تضف مفتاح service-role إلى Cloudflare أو المتصفح.
- مصدر وظيفة Supabase هو `supabase/functions/sekka-api/index.ts`، ومساراتها موثقة في [توثيق API للمرحلة 11](docs/pool-phase-11-api.md).
- تغييرات قاعدة البيانات موجودة في `supabase/migrations`. راجع [حالة ترحيل Supabase وإعداداته](docs/supabase-migration.md) قبل تطبيق أي migration أو إعداد خدمة.

## الخرائط والتوجيه

- تعرض الخريطة بلاطات OpenStreetMap العامة مع إظهار نسب البيانات إلى OpenStreetMap.
- حساب مسارات الطرق والأجرة يحتاج خدمة OSRM متوافقة وخاصة. الخدمة يجب أن تكون قابلة للوصول من Supabase Edge Function، وتُضبط في سرّ Edge Function باسم `SEKKA_ROUTING_URL`.
- عنوان `http://127.0.0.1:5000` مخصص لتطوير الخادم المحلي فقط؛ لا يمكن لخدمة Supabase المستضافة الوصول إلى جهازك عبر loopback.
- لا ترسل إحداثيات الركاب إلى خدمة توجيه عامة. عند عدم إتاحة خدمة التوجيه، يرفض الخادم إنشاء المجموعة بدل حساب أجرة خط مستقيم.

## تدفقات المنتج

- تسجيل الراكب والكابتن، الجلسات والصلاحيات، طلبات الرحلات والحجز والمطابقة.
- الراكب يختار مواقع الرحلة وأيام الخدمة والمواعيد، ويتابع مجموعاته وحجوزاته وإشعاراته.
- الكابتن يدير الملف والقدرات، يرى العروض، يقبل الرحلات ويتابع نقاطها ويسجل الإكمال أو الغياب.
- الإدارة تراجع الكباتن والأسعار والمدفوعات ومؤشرات التشغيل، ويمكنها تشغيل أو إيقاف OTP من لوحة الإدارة.
- Faster: الحد الأدنى راكبان والسعة 3. Saver: الحد الأدنى 3 ركاب والسعة 4.
- الباقة الأسبوعية 5 أيام بخصم 5%، والشهرية 22 يومًا بخصم 10%. أيام الخدمة يحددها الراكب من الأحد إلى الخميس.
- بعد 72 ساعة من الانتظار دون اكتمال الحد الأدنى، تُتاح خيارات الانتظار أو حجز المقاعد الباقية أو الإلغاء المجاني.
- إذا زادت المسافة أكثر من 15%، يتطلب السعر الجديد موافقة الركاب؛ ويُحذف من يرفض دون غرامة، وتُلغى الرحلة مع استرداد كامل مستحق إذا لم يعد الحد الأدنى قائمًا.
- العمولة المحاسبية 20% للشركة و80% للكابتن، وتتحمل الشركة الخصومات حتى 10%. تسجيل التسويات فقط؛ تحصيل الدفع وتنفيذ الاسترداد مؤجلان.

## إعدادات التشغيل التي ما زالت مطلوبة

- تشغيل إنشاء الرحلات المستضافة يتطلب نشر خدمة OSRM خاصة وضبط `SEKKA_ROUTING_URL` في Supabase.
- OTP مبني وموقوف افتراضيًا. لتفعيله، أضف أسرار Twilio Verify إلى Supabase ثم شغّله من إعداد OTP في لوحة الإدارة.
- إرسال Web Push غير منفذ بعد؛ التطبيق يحفظ الاشتراكات ويعرض صندوق الإشعارات داخل التطبيق.
- أنشئ حساب الإدارة عبر إجراء تشغيلي آمن؛ لا تستخدم كلمة مرور افتراضية أو حساب تطوير في الإنتاج.
- الدفع الحقيقي وبوابة الدفع والاستردادات الفعلية مؤجلة حسب قرار المنتج.

تفاصيل المسارات والحقول وقواعد العمل في [توثيق API](docs/pool-phase-11-api.md).
