# سِكّة | SeKKa

تطبيق رحلات مشتركة يومية وباقات أسبوعية وشهرية بواجهة عربية RTL. النسخة المنشورة تستخدم Supabase Edge Function لواجهات API؛ مجلد Express/SQLite القديم باقٍ كبيئة تطوير محلية منفصلة ولا يمثل قاعدة بيانات الإنتاج.

## نموذج التشغيل والنموذج المحلي القديم

التعديلات والنشر الحاليان يمران عبر فرع GitHub وCloudflare Pages وSupabase المحددين للمشروع. التعليمات التالية تخص نموذج Express/SQLite القديم للتطوير فقط، ولا تعكس إعدادات النسخة المنشورة.

### تشغيل النموذج المحلي القديم

يتطلب Node.js 22 أو أحدث. افتح نافذتي PowerShell من مجلد المشروع:

```powershell
# النافذة الأولى: الخادم وواجهات API
cd server
npm install
npm run dev
```

```powershell
# النافذة الثانية: واجهة الويب
cd web
npm install
npm run dev
```

افتح `http://127.0.0.1:5173/`. الواجهة تمرر طلبات `/api` تلقائيًا إلى الخادم على المنفذ 3001. يتأكد من جاهزية الخادم عبر `http://localhost:3001/api/health`، وتُنشأ قاعدة البيانات تلقائيًا في `server/data/sekka.db`.

## إعداد التوجيه والخرائط

- يستخدم مسار الإنتاج بلاطات OpenStreetMap العامة عبر Leaflet وبنسبة بيانات ظاهرة؛ اختيار الموقع يتم بالنقر فقط ولا يوجد بحث نصي.
- يحسب Supabase Edge Function الطريق الفعلي عبر خدمة OSRM في `SEKKA_ROUTING_URL`، والإعداد الحالي الافتراضي هو `https://router.project-osrm.org`. يرسل الخادم إحداثيات محطات الرحلة إلى مزود التوجيه العام عند حساب الطريق.
- خدمة OSRM العامة تجريبية وبأفضل جهد بلا ضمان توافر. إذا تعذر حساب الطريق، تعرض الواجهة رسالة خطأ ولا تستبدله بخط مستقيم. بلاطات OSM لا تُحفظ أو تُحمّل مسبقًا للعمل دون اتصال.
- إعدادات OSRM المحلية في خادم Express القديم منفصلة عن إعداد Supabase Edge Function ولا تُستخدم في النسخة المنشورة.

## الفلو المتاح

- تسجيل الراكب أو الكابتن وتسجيل الدخول وإدارة كلمة المرور.
- الراكب يحدد المواقع على الخريطة، الفئة، أيام الخدمة والمواعيد؛ ويستطيع إنشاء مجموعة ومشاركتها ومتابعة الركاب والرحلات والإشعارات.
- الكابتن يكمل ملف المركبة والتحقق التطويري للهاتف، يحدّث موقعه وقدراته، يقبل المسارات ويتابع نقاط الركوب والنزول.
- الإدارة تراجع توثيق الكباتن وتتابع مؤشرات التشغيل.
- Faster: مقاعد 3، والحد الأدنى راكبان. Saver: مقاعد 4، والحد الأدنى 3 ركاب. الباقة الأسبوعية 5 أيام بخصم 5%، والشهرية 22 يومًا بخصم 10%.
- الدفع الفعلي وبوابة الدفع وتسوية العمولة مؤجلة. تحتفظ المنظومة بالمبالغ والاستردادات المستحقة كبيانات تشغيلية فقط.
- إشعار عدم اكتمال الحد الأدنى يُعالج بعد 72 ساعة، ويتيح الانتظار أو حجز المقاعد المتبقية أو الإلغاء المجاني.

تفاصيل جميع المسارات والحقول والردود في [توثيق API للمرحلة 11](docs/pool-phase-11-api.md).

## حساب الإدارة المحلي

قاعدة البيانات الجديدة تهيئ حساب إدارة تطويريًا موضحًا في migrations. استخدم بيانات الدخول المحلية للتطوير فقط وغيّر كلمة المرور مباشرة بعد أول تسجيل دخول؛ لا تستخدم الحساب الافتراضي في الإنتاج.
