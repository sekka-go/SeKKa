# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions. Use the repository's **Security → Report a vulnerability** private reporting flow on GitHub. If private vulnerability reporting is unavailable, contact the repository maintainers privately through their GitHub profiles and include the affected endpoint/file, impact, and a safe reproduction. Do not include real user data or live credentials in the report.

We will acknowledge reports as soon as practical, assess severity and affected releases, and coordinate a fix and disclosure date with the reporter.

## Supported versions

Security fixes are made on the current default branch. Deployments should use the latest reviewed release/commit.
