# مركز إشعارات سِكّة

مواصفات واجهة RTL ومخطط البيانات ومثال React Native. لغة الواجهة عربية مصرية، واتجاهها من اليمين لليسار.

## مواصفات التصميم لـ Figma

### بنية العنصر

- سطح القائمة: خلفية `#111827`، مساحة داخلية 16px، وفاصل 8px بين العناصر.
- عنوان المجموعة: 12px، وزن 700، رمادي ثانوي. الأقسام: «الجديد»، «اليوم»، «سابقاً».
- صف الإشعار: Auto layout أفقي RTL، فجوة 12px، padding ‏12px، نصف قطر 16px، وارتفاع مرن بحسب المحتوى.
- الصورة الرمزية: دائرة 48×48px (على الشاشات الصغيرة 42×42px). استخدم صورة الحساب عند توافرها، وأول حرف من الاسم كبديل، وشعار سِكّة للتنبيهات الإدارية.
- شارة النوع: دائرة 18px مثبتة أسفل الصورة من جهة البداية. أيقونتها مختصرة وواضحة، ولونها يطابق نوع الحدث.
- النص: سطر فاعل بخط 14px؛ اسم الفاعل عريض ثم وصف الفعل. العنوان/الحدث 13px، المسار 12px بلون العلامة، والمعاينة المقتبسة 12px بلون ثانوي.
- الوقت النسبي وقائمة الثلاث نقاط في جهة النهاية، ويظلّان محاذيين أعلى الصف عند تعدد الأسطر. القائمة تعرض «تعليم كمقروء»، «حذف الإشعار»، و«كتم إشعارات المشوار» عندما يرتبط الإشعار بمشوار.

### الألوان والحالات

| الحالة | اللون / المعالجة |
| --- | --- |
| مشوار أو حجز | أخضر `#42A66A` |
| محادثة | أزرق `#3287D5` |
| تقييم | ذهبي `#E8B922` |
| تغيير أو إلغاء | أحمر برتقالي `#E3604B` |
| النظام | رمادي أزرق `#718096` مع شعار سِكّة |
| غير مقروء | خلفية العلامة بعتامة 5.5% وحدّ ناعم؛ النص كامل الوضوح |
| مقروء | خلفية شفافة وحدود محايدة؛ النص الثانوي بعتامته القياسية |
| تركيز لوحة المفاتيح | حد 2px بلون العلامة مع إزاحة 2px |

استخدم شبكة 8px: 8px للأيقونة، 16px للحشو المعتاد، 24px لفصل المجموعات. في عرض الهاتف حافظ على الصورة والوقت والقائمة، واسمح للنص بالالتفاف.

### السلوك الوظيفي

1. رتّب الأحدث أولاً. اجمع غير المقروء تحت «الجديد»، ثم المقروء من تاريخ القاهرة الحالي تحت «اليوم»، والباقي تحت «سابقاً».
2. الضغط على الصف يعلّم الإشعار كمقروء. قائمة الثلاث نقاط تتيح التعليم كمقروء والحذف المنطقي. خيار الكتم يظهر فقط لإشعارات المشاوير ويوقف الإشعارات المستقبلية لذلك المستخدم والمشوار.
3. الحذف يضبط `deleted_at` بدلاً من الحذف الفعلي كي لا يعاد إنشاء الحدث بسبب قيد منع التكرار.
4. الرسائل والتقييمات تعرض `payload.preview` أو `payload.quote` كسطر ثانوي. المسار يعرض `origin` و`destination` عند توفرهما.
5. يدعم اسم الفاعل وصورته اختيارياً؛ عدم وجود صورة لا يمنع العرض. التنبيهات الإدارية تعرض علامة سِكّة.

## نموذج البيانات

الـ API يعيد `read_at` و`created_at` لأجل التوافق مع التطبيق الحالي. `is_read` في JSON Schema حقل مشتق يعادل `read_at IS NOT NULL`، و`timestamp` يقابل `created_at`. كتم الإشعارات محفوظ في `pool_notification_mutes` بمفتاح المستخدم والمشوار.

المسارات المتاحة للمركز: `GET /pool/notifications`، و`POST /pool/notifications/:id/read`، و`POST /pool/notifications/:id/delete`، و`POST /pool/notifications/:id/mute`.

المخطط الآلي: [notification.schema.json](./notifications-center/notification.schema.json). مثال React Native مع NativeWind: [NotificationFeed.example.tsx](./NotificationFeed.example.tsx).
