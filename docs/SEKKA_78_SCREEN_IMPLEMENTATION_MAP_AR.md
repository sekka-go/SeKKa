# سِكّة — خريطة تنفيذ الشاشات الـ78

هذه الوثيقة تربط خريطة المنتج المقدمة من صاحب المشروع بالكود الحالي. إدراج الشاشة في الخريطة لا يعني وحده أن وظيفتها مكتملة أو متصلة بالخادم.

## النطاق المعتمد
- 7 شاشات عامة + 24 للراكب + 24 للكابتن + 23 للإدارة = 78 شاشة.
- المرجع: `SeKKa_Master_Screen_Map_MVP_v1_AR.md`.
- المنصة PWA، العربية RTL، مع دعم الشاشات الصغيرة.
- Telegram للتحقق واستعادة الحساب فقط، وليس لتسجيل الدخول.
- عمولة المنصة على الكابتن؛ النسبة والتحصيل الإلكتروني مؤجلان. لا نفترض وجود دفع إلكتروني.
- لا نعرض رحلة مؤكدة أو دفعًا ناجحًا أو تقييمًا أو إحصائية إلا إذا دعمتها بيانات فعلية.

بعض بنود الخريطة حالات داخل تدفق وليست بالضرورة صفحة مستقلة. يجب مراجعة كل بند مقابل الكود وواجهات API واختباراته، وعدم اختراع مسارات مالية أو تشغيلية غير موجودة.

## طبقة الواجهة
- `bright-product-system.css` يطبق لوحة زاهية على التطبيق الفعلي: أخضر زمردي ونعناعي، أبيض دافئ، أصفر شمسي ولمسات سماوية.
- تم ربط الملف في `main.tsx` بعد أنظمة التنسيق السابقة حتى تكون القواعد البصرية الجديدة هي الغالبة.
- هذه خطوة بصرية أولى وليست ادعاءً بأن الشاشات الـ78 كلها مكتملة وظيفيًا.
