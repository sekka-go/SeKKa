# سِكّة — إعادة البناء من الصفر

## المرحلة التأسيسية
العمل في الفرع `rebuild/clean-foundation` مستقل عن `main`. لن تُحذف ملفات التطبيق القديمة قبل تدقيقها، ولن تُمس قاعدة بيانات Supabase أو الحسابات من هذا الفرع.

## خطة التنفيذ
1. اعتماد خريطة الشاشات الرسمية والقرارات السابقة.
2. مراجعة المصادقة والصلاحيات وعقود API وسياسات Supabase.
3. إنشاء نقطة دخول جديدة وواجهة عربية RTL متجاوبة.
4. بناء الشاشات والوظائف على دفعات، مع حالات التحميل والفراغ والخطأ والنجاح.
5. تشغيل typecheck/build/lint والاختبارات قبل اقتراح الدمج.

## حدود هذه المرحلة
الواجهة التأسيسية لا تعني أن الشاشات الـ78 أو التكاملات الخلفية اكتملت. لن نعرض حجوزات أو مدفوعات أو بيانات تجريبية على أنها حقيقية. لم تُحذف الحسابات أو جداول قاعدة البيانات.

## معيار قبول الشاشة
لا تُعد الشاشة مكتملة بمجرد وجود تصميم أو رابط؛ يجب أن تكون مرتبطة بمصدر البيانات الصحيح، وتراعي الصلاحيات، وتتعامل مع التحميل والفراغ والأخطاء والنجاح، وتُختبر فعليًا.
