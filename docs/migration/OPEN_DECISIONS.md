## تعارضات المصدر التي تحتاج تثبيتًا قبل مرحلة التصميم

- PRD v1.0 يجعل حساب سعر المركبة ومداه من إعدادات المالك، بينما Stitch PRD v2 يقترح سعرًا تلقائيًا 7–11 جنيه/كم. مصدر السلوك PRD v1.0؛ اعتماد حدود السعر النهائية يظل للمالك ضمن إعداداته.
- ملف Stitch يصف محفظة/بطاقات/فوري/سحب أرباح/إكراميات ومشاوير فورية؛ PRD يستبعد بوابة الدفع والتحصيل داخل التطبيق والتقييم العلني والمدن خارج القاهرة والجيزة. هذه عناصر خارج التنفيذ ما لم يتغير PRD بإصدار معتمد.
- تصدير Stitch يفتقد SCR-08 وSCR-72، ويضم أربع مجلدات `sekka_1..4` تبدو تكرارات. يلزم تزويد/تثبيت النسخة الصحيحة قبل الادعاء أن كل 80 شاشة مطبقة.
